##  Уроки пользования GitHub
### Создание новой ветки и подготовка к Pull Request состоит из нескольких простых шагов в терминале.

1. Переход в базовую ветку
Убедитесь, что вы находитесь в актуальной ветке main, от которой будете наследоваться:

   **git checkout main** или 
 
   **git pull origin main** (для подтягивания последних обновлений с сервера)

2. Создание и переход в новую ветку
Создайте новую ветку (например, для второй лабораторной работы назовем ее lr2) и сразу переключитесь на нее с помощью флага -b:

   **git checkout -b lr2**

3. Написание кода и фиксация изменений
Теперь вы работаете в изолированной ветке lr2. Добавляйте новые файлы, пишите код, а затем сохраните изменения стандартным способом:

   **git add .**

   **git commit -m "Реализация REST API для второй лабораторной"**

4. Первая отправка ветки на сервер
Так как ветки lr2 еще нет на удаленном сервере, при первой отправке нужно связать локальную ветку с удаленной с помощью флага -u:

   **git push -u origin lr2**

   В дальнейшем при работе в этой ветке будет достаточно писать просто **git push**.

5. Создание Pull Request в браузере
После успешной отправки зайдите на страницу вашего репозитория (в GitHub, GitLab или другой системе). Там автоматически появится всплывающее уведомление и кнопка "Compare & pull request" (или "Create merge request"). Нажмите на нее, убедитесь, что базовой веткой (base) указана main, а веткой сравнения (compare) — lr2, и подтвердите создание запроса на слияние.
